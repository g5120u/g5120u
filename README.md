| 模型協作 | 用 AI 協助整理方案、產生修改、定位可能問題 | 能說明我給了什麼限制與驗收條件 |
| 結果驗收 | 用實機畫面、log、截圖、回歸檢查確認結果 | 能拿出驗收方式與問題排查紀錄 |
| 交付掌控 | 不把沒驗過、看不出行為結果的修改當成完成 | 能現場展示指定流程的結果 |

> 我不把「AI 產生了程式」當成完成；我看重的是需求是否被正確拆解、畫面與流程是否符合預期、問題是否能被重現與驗收。
